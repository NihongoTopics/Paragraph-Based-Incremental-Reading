# 手のかかるページ

SKILL.md の手順 4。スキャンのページ（OCR の文字のあるもの、無いもの）、図・写真・グラフ・樹形図・表・数式のあるページ、
2 段組や複数の言語で下書きが崩れているページに使う。`S`, `PY`, `WORK` は SKILL.md と同じ。
書き方の規則は `markup.md`（図、表、数式は `figures-tables-math.md` も）。

## 1 OCR の文字を確かめ、必要なら読み直す

- `scan` のページは OCR する。
- `scan-ocr` と `scan-text` のページは、`text/pNNNN.txt` とページの画像を見比べる。別の言語で OCR されている、
  用字が落ちている（日本語のページなのに仮名が無い、など。prepare.py の表の scripts でも分かる）、
  文字化けが多い、のどれかなら OCR し直す。

```
$PY $S/ocr.py WORK --lang jpn+eng --pages 3-8
$PY $S/draft.py WORK --pages 3-8
```

- `--lang` は画像を見て決め、いちばん多い言語を先に書く。`jpn+eng` と `eng+jpn` では結果が違う
  （後者は日本語の字の間に空白を入れる。2026-09-25 の検証）。縦書きの日本語は `jpn_vert`。
  使える言語は setup.py の表示か `tesseract --list-langs`。2 段組は既定の `--psm 3` で段が分かれる。
- tesseract が無い環境では OCR を飛ばし、拡大した画像から読む。照合（5）の相手が無いので、読み終えたら
  もう一度画像と見比べて読み直す。

## 2 読む

1. ページの画像 `pages/pNNNN.png` を見る（組み方を見るための大きさ。字は読めないことがある）。
2. `draft/pNNNN.html` を読む。
3. 画像と下書きを突き合わせて `frag/pNNNN.html` を書く。
   - 下書きの見出し（`<h1>`〜`<h6>`）は、テキストレイヤでは字の大きさと太字、OCR では行の高さから draft.py が付けたもの。
     画像と見比べて直す（数式の行、表の見出しのセル、著者の行が見出しになっていることがある）。見出しを `<p>` で書かない
     （カードになる）。
   - `digital` のページは下書きの文字（テキストレイヤ）を使い、構造だけを直す。文字を打ち直さない
     （`draft.py --frag` で清書に写し、その場で直してよい）。数式はテキストレイヤでは崩れるので、画像から TeX で書く。
   - OCR のページ（`scan-ocr`, `scan-text`, OCR し直したページ）は、下書きの文字を画像と 1 行ずつ見比べて直す。
     OCR が正確でも誤りはあるので、見比べずに写さない。段ごと（1 段組なら上下の半分ごと）に拡大して読む。
   - 下書きが役に立たないページ（読み直しても崩れている）は、拡大した画像から読んで書く。
   - 拡大: `$PY $S/crop.py WORK N --box x0,y0,x1,y1 --zoom`（標準の大きさ。小さすぎて読めないときだけ `--large`。
     トークンが約 3 倍になる）。座標は下書きの `data-box` か、`$PY $S/crop.py WORK N --grid` で作る目盛り付きの画像
     `pages/pNNNN.grid.png` から読む。
   - 読めない文字は推測で埋めない（markup.md の 11）。
   - 前のページから続く段落には `data-pdf-cont`（markup.md の 4）。前のページの末尾を確かめてから付ける。

下書きの限界（2026-09-26 に試験用の PDF で見たもの）: 図の中の文字（グラフの目盛り、樹形図のラベル）と表のセルは
ばらばらの段落として出る。数式は崩れた文字の段落になる。文の中の別の字体の語（英文の中の日本語の語など）は、
行から外れて別の段落になることがある。回転したページでは、poppler が日本語の字の順を逆に出すことがある。
どれも画像を見て直す。

## 3 図、写真、グラフ、樹形図

1. `$PY $S/regions.py WORK N` で候補の範囲を出す。候補の座標がそのまま出るので、まずそれで切り出す。
   スキャンのページでは、先に OCR の行（テキストレイヤか ocr.py の結果）が要る。スキャンでは図が 2 つに分かれたり、
   式や汚れが候補に入ったりする。そのときだけ `pages/pNNNN.regions.png`（番号付きの枠）や grid の画像を見る。
2. `$PY $S/crop.py WORK N --box x0,y0,x1,y1 --out figs/pNNNN-1` で切り出す。
3. 切り出した画像を見て、図が欠けていないか、キャプションや本文が入っていないかを確かめ、ずれていれば範囲を直して切り直す。

## 4 数式

TeX で書く（`figures-tables-math.md` の 8）。TeX に誤りが無いかは `$PY $S/tex2mml.py 'TeX' [--display]` で確かめられる
（誤りがあれば終了コード 1）。式の番号は `\tag{1}` で書く。node が無い環境では MathML にできないので、止める。

## 5 照合

```
$PY $S/compare.py WORK N
```

清書の文字を、テキストレイヤか OCR の読みと突き合わせる。一致しない行と、清書にだけある語句が、ページ上の範囲付きで出る
（拡大のコマンドは最初に 1 行だけ出る）。一つずつ拡大して確かめ、清書が誤っていれば直す。参照の読み（OCR）の方が
誤っている場合はそのままでよい。柱とページ番号、regions.py の図の範囲の中の行は比べない。数式の行は `<tex>` を比べないので
一致しない行に出る（`[math]` と付く）。表のセルは読む順が違うと出る。これらは画像で確かめれば足りる。
文字を下書きから写しただけのデジタルのページには要らない。

## 6 長い PDF

目安として 15 ページを超えるときは、サブエージェントを使える環境（Claude Code の Agent ツールなど）なら、手のかかるページを
ページの範囲（1 範囲 10 ページまで）に分けて任せてよい。下調べ、組み立て、点検は自分で行う。サブエージェントには次を渡す。

- SKILL.md とこのファイルと markup.md（要れば figures-tables-math.md）のパス、`S`、`PY`、`WORK`、担当のページの範囲、
  文書の主な言語、下調べで分かったこと（段組、柱の文字、OCR し直したページ）。
- 書くのは担当のページの `frag/` だけであること。最初のページは前のページの末尾を確かめて `data-pdf-cont` を決めること。
- 返すもの: 書いたファイル、読めなかった箇所、画像にした数式や表、迷った判断。

範囲の境目のページは、組み立てのあとで check.py の「続きらしいカード」の警告で確かめる。
